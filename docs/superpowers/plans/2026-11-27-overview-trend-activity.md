# 概览趋势与活动日历实施计划

[对应设计](../specs/2026-11-27-overview-trend-activity-design.md)

1. 在现有趋势测试加入刻度、峰值、汇总文案、零与单点用例。确认新增断言失败后，实现共享纵轴比例，保留数据点的键盘详情。
2. 在现有日历测试覆盖同周、跨月、多周、53 周边界、区间外和未来占位。先复现固定 53 周的问题，再让网格随所选自然周数变化，接入可键盘操作的视图切换并复测。
3. 复用 Electron 布局测试的合成数据入口，在 1024 × 680 检查刻度、月份、星期、焦点和提示。验证 53 周展开与回切，检查中英文、深浅主题，并留存代表性截图。
4. 运行 `npm test`、`npm run typecheck`、`npm run lint` 和 `npm run test:layout`。对照设计核验变更。
