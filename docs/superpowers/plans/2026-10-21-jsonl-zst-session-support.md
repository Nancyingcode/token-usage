# 压缩会话手动导入实施计划

状态：按用户确认的[设计](../specs/2026-10-21-jsonl-zst-session-support-design.md)完成开发与验证，保留工作区改动。本计划不授权 Git 提交或推送。

## 目标与约束

普通 JSONL 保持自动刷新；压缩来源只在用户点击独立按钮后导入。完整解压原文保存在应用拥有的目录，原始会话目录始终只读。实时集合与本地导入集合独立维护，合并后按逻辑来源去重。导入失败不能破坏旧文件或已交付结果。
