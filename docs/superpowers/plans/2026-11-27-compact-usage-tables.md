# 会话与项目列表窄窗口实施计划

[对应设计](../specs/2026-11-27-compact-usage-tables-design.md)

1. 在列表测试复现没有可展开行详情的问题。覆盖两张表的次要指标、详情与既有操作互相独立，以及筛选、排序或翻页后的行身份。
2. 新增两张表共用的原生详情控件，复用已有文案和 formatter。按各表可用宽度切换显示列，检查精确数值和长文本的换行。
3. 用隔离的 Electron 合成数据检查 1024 × 680 和宽窗口的表头、滚动、空态、焦点、宽度切换和下钻。覆盖中英文、深浅主题并保留代表性截图。
4. 运行定向测试和项目门禁，核对文档链接、UTF-8 编码和变更差异。
