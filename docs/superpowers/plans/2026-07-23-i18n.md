# English and Chinese i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add synchronized, persisted English and Simplified Chinese localization to the React renderer and Electron main-process notifications.

**Architecture:** Bundle typed `en` and `zh-CN` resources in `src/shared/i18n`, then initialize independent i18next instances in the main and renderer processes. The main process owns the resolved locale and persisted override; typed IPC broadcasts committed changes to the renderer. Domain models expose semantic alert, warning, and validation codes so presentation layers translate them at render time.

**Tech Stack:** TypeScript 5.5, Electron 31, React 18, i18next, react-i18next, Intl, Vitest

## Global Constraints

- Supported locales are exactly `en` and `zh-CN`.
- Any system locale beginning with `zh` resolves to `zh-CN`; every other or invalid locale resolves to `en`.
- English is the runtime fallback locale.
- User-selected locale is persisted in Electron `userData`; there is no “follow system” selector after the first resolution.
- Renderer and main process use separate i18next instances with the same statically bundled resources.
- Model IDs, aliases, paths, budget arithmetic, date boundaries, sorting keys, and USD pricing semantics do not change with display locale.
- App-owned visible and accessibility copy is localized; user data, file paths, model IDs, project names, and raw technical error details remain unchanged.
- Use function components declared as `React.FC`; do not introduce class components, `any`, `var`, or magic numeric literals.
- JSX conditions combining multiple business predicates must use named booleans or pure helpers.
- New shared services and complex files receive concise responsibility-oriented file headers following `rules/file-header.md`.
- Every behavior change follows red-green-refactor and every task ends with a focused commit.

- `src/shared/i18n/locale.ts`: supported locale type, runtime guard, and system-locale resolution.

- `src/renderer/utils/validationMessages.ts`: validation-code-to-translation mapping.
- `src/renderer/utils/usageWarnings.ts`: warning-code-to-translation mapping.
- `tests/i18nTestUtils.tsx`: isolated renderer i18next provider for component tests.

### New tests

- `tests/i18n.test.ts`: locale resolution, resource parity, fallback, interpolation, and plural behavior.
