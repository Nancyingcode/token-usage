# 项目分析工作台实施计划

## 1. 实施目标

按照已确认的《项目分析工作台设计》，在不改变数据扫描、聚合和会话导航语义的前提下，将项目页升级为“概览指标 + Top N 占比图 + 可搜索排序的完整项目表格”，并将侧栏项目图标调整为符合项目语义的文件夹图标。

## 2. 任务拆分

### 任务一：建立项目视图模型回归测试

涉及文件：

- `tests/projectViewModel.test.tsx`
- `tests/projectDonutGeometry.test.tsx`
- `src/renderer/utils/projectViewModel.ts`

红—绿—重构：

1. 先测试 Top 七项目与“其他项目”的稳定聚合、占比闭合和输入不变性。
2. 测试按项目名/路径搜索，以及按 Token、会话数、最后活跃时间和名称排序。
3. 测试平均 Token/会话与缓存率的零值边界。
4. 实现无副作用的纯函数并运行两个最小测试文件。

### 任务二：建立项目页面结构与交互回归测试

涉及文件：

- `tests/analyticsViews.test.tsx`
- `tests/appContent.test.tsx`
- `src/renderer/components/ProjectsView.tsx`

红—绿—重构：

1. 先添加概览指标、项目表格列和明确“查看会话”按钮的失败断言。
2. 添加搜索项目名/路径、无结果后清除搜索的交互测试。
3. 添加排序切换测试，确认表格行顺序变化且导航仍传递完整路径。
4. 添加 Top N 图表测试，确认“其他项目”不可导航，真实项目仍支持点击与键盘操作。
5. 实现页面状态、派生视图模型、语义表格和显式操作。
6. 运行项目页面与应用内容最小测试集。

### 任务三：补齐国际化、视觉与菜单语义

涉及文件：

- `src/shared/i18n/locales/en.ts`
- `src/shared/i18n/locales/zhCN.ts`
- `src/renderer/styles/views.css`
- `src/renderer/components/Sidebar.tsx`
- 必要时更新 `tests/i18n.test.ts`、`tests/sidebar.test.tsx` 与 `tests/uiStylePolicy.test.ts`

红—绿—重构：

1. 通过组件测试声明新增中英文文案需求。
2. 增加概览、搜索、排序、列标题、操作、无结果和“其他项目”文案。
3. 实现概览卡、紧凑占比图、工具栏、响应式表格和键盘焦点样式。
4. 将“项目”入口的扳手图标替换为文件夹项目图标，不改变内部 `ViewKey`。
5. 运行 i18n、侧栏、样式策略和项目页面测试。

### 任务四：完整验证与收口

1. 检查 Git diff，确保没有覆盖无关工作区修改。
2. 运行 `npm test`。
3. 运行 `npm run typecheck`。
4. 运行 `npm run lint`。
5. 仅在三项全量检查全部通过后声明完成。

## 3. 实施约束

- 不修改 `UsageProject`、项目聚合规则、Electron 主进程、preload 或 IPC。
- 不猜测未知模型价格，也不新增费用声明。
- Renderer 不访问文件系统；局部搜索与排序状态不持久化。
- 纯函数不修改输入对象或数组。
- 新增文案同时维护英文和简体中文。
- 交互使用原生可聚焦控件，颜色不作为唯一信息表达。

## 4. 完成定义

- 页面首屏包含四项项目概览指标和最多八段的占比图。
- 完整项目表格可按名称或路径搜索，并按四种口径排序。
- 用户可通过明确按钮进入项目会话，“其他项目”不会触发错误导航。
- 零 Token、零会话、未知项目和无搜索结果均有稳定表现。
- 最小回归与全量测试、类型检查、lint 全部通过。
