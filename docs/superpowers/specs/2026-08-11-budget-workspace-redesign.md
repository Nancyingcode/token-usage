# 预算工作台改造设计

## 1. 背景

当前“预算中心”已经具备预算策略、告警阈值、模型价格和未知模型补价能力，但页面组织仍有以下问题：

- 页面加载或失败时由 `AppContent` 渲染通用状态，标题、说明和操作入口会消失；“成本优化”页面则始终保留完整工作台上下文。
- “预算概览”同时放置摘要、告警、筛选器和策略表，概览信息与配置操作混在同一层级。
- 标签页由 `BudgetsView` 内部维护，系统通知跳转和未知模型补价需要通过一次性局部状态间接切换页面，顶层导航无法表达当前预算子页面。
- 告警阈值、添加预算和模型价格属于不同层级的操作，但目前都围绕同一个概览标签组织，页面动作的归属不够清晰。

本次改造参考“成本优化”菜单的工作台结构，统一预算页的信息架构、状态呈现和导航方式，不改变预算计算、计价、通知或持久化规则。

## 2. 目标

- 预算页在加载、失败、过期和就绪状态下保持一致的页头与工作台结构。
- 将预算功能拆分为“总览”“预算策略”“模型价格”三个职责单一的标签页。
- 标签页由应用顶层导航状态控制，支持通知跳转、未计价模型补价和页面操作的确定性导航。
- 将告警阈值作为预算工作台设置，从任意标签页均可进入。
- 保留现有预算策略 CRUD、筛选、告警关闭、模型价格覆盖和未知模型补价能力。
- 延续成本优化页的 `PageHeader`、`AccessibleTabs`、`StatusBanner`、`LoadingSkeleton`、抽屉和 Toast 交互模式。
- 保持英文和简体中文资源完整对齐，并满足键盘操作、焦点管理和辅助技术反馈要求。

## 3. 非目标

- 不修改预算周期、阈值判断、计价公式或预算状态算法。
- 不新增预算类型、通知类型、货币或云端同步能力。
- 不修改主进程存储格式、IPC 契约或 preload API。
- 不把成本预测、异常检测或节省建议复制到预算页；这些能力继续属于“成本优化”。
- 不新增项目下拉筛选。预算策略同时包含全局与项目范围，直接套用成本优化的项目筛选会隐藏仍然适用的全局预算，并引入额外的范围语义。
- 不在本次改造中新增图表、严重程度筛选或摘要卡点击下钻。

## 4. 核心产品决策

### 4.1 采用三标签工作台

预算页使用以下标签：

1. **总览**：展示预算健康摘要、当前告警和未计价模型入口。
2. **预算策略**：展示范围与周期筛选、策略列表以及编辑和删除操作。
3. **模型价格**：保留现有价格目录、覆盖、恢复默认和未知模型补价能力。

原“预算概览”中的策略表移入“预算策略”。总览不再承担策略管理，避免摘要信息与配置表竞争页面空间。

### 4.2 页头动作保持全局可用

预算快照就绪时，页头展示：

- 当前警告阈值和严重阈值摘要。
- “预算设置”按钮，用于打开阈值设置抽屉。
- “添加预算”按钮，用于切换到“预算策略”并打开新增抽屉。

加载和失败时保留同一页头，但禁用依赖预算快照的动作。这样用户始终知道当前所在功能，同时不会在数据不可用时启动无效编辑。

### 4.3 标签状态提升到应用导航

在 `AppNavigationState` 增加 `activeBudgetTab`，类型为：

```ts
type BudgetTab = 'overview' | 'policies' | 'pricing';
```

顶层 reducer 处理预算标签切换，`BudgetsView` 只接收当前值和 `onActiveTabChange`。离开预算菜单再返回时保留上次选择，与成本优化页一致。

跨功能导航规则如下：

- 点击系统预算通知：进入“预算策略”，打开对应策略抽屉。
- 在总览点击未计价模型的“添加价格”：进入“模型价格”，打开对应模型价格编辑器。
- 点击页头“添加预算”：进入“预算策略”，打开新增预算抽屉。
- 完成保存后停留在当前目标标签，通过 Toast 宣告成功。

### 4.4 总览使用现有快照派生数据

总览不新增领域字段或 IPC 数据。展示内容全部从 `BudgetSnapshot` 派生：

- 已配置预算：`snapshot.statuses.length`。
- 接近上限：`snapshot.summary.warningCount`。
- 超出预算：`snapshot.summary.overCount`。
- 未计价模型：`snapshot.summary.unpricedModelCount`。

四张摘要卡与成本优化总览的指标层级保持一致。当前预算告警和未计价模型提示继续使用现有 `BudgetAlertBanner`；关闭告警仍然只影响本次渲染会话，不修改通知回执和预算状态。

### 4.5 设置与编辑抽屉职责分离

- 阈值设置继续复用 `BudgetDrawer` 的阈值模式，但入口命名为“预算设置”，表达其工作台级作用。
- 新增或编辑策略继续使用策略模式。
- 模型价格编辑继续由 `ModelPricingView` 管理。
- 同一时刻只显示一个覆盖层；打开新目标前关闭已有覆盖层。

现有 Dialog、Drawer 的初始焦点、焦点约束、Escape 关闭和关闭后焦点恢复行为必须保留；若现有实现缺失，则在本次受影响覆盖层中补齐并添加回归测试。

## 5. 页面状态模型

`BudgetsView` 与 `CostOptimizationView` 使用相同的内容模型边界：

```ts
type BudgetContentModel =
  | { kind: 'loading' }
  | { kind: 'error'; message: string }
  | { kind: 'ready'; snapshot: BudgetSnapshot };
```

渲染规则：

- `loading`：显示页头和 `LoadingSkeleton`，不渲染标签页内容。
- `error`：显示页头和错误状态面板，不渲染旧快照或编辑入口。
- `ready + fresh`：显示标签页与所选内容。
- `ready + stale`：在标签页之前显示 `StatusBanner`，随后继续展示上一份可用快照。

`AppContent` 不再为预算页单独构造加载、错误和占位分支，只负责把内容模型和动作传给 `BudgetsView`。这样预算页的所有视觉状态由一个组件边界负责。

## 6. 组件调整

### 6.1 `App.tsx`

- 在应用导航状态中增加 `activeBudgetTab`。
- 增加 `select-budget-tab` 动作及稳定回调。
- 通知导航同时选择 `budgets`、`policies` 和对应策略 ID。
- 将受控标签状态和回调传给 `AppContent`。

### 6.2 `AppContent.tsx`

- 删除预算专用的加载、失败和占位渲染函数。
- 无论预算模型为何种状态，都渲染 `BudgetsView`。
- 继续传递 `BudgetActions`、通知聚焦策略 ID 和消费回调。

### 6.3 `BudgetsView.tsx`

- Props 从独立 `snapshot` 改为 `model`，并增加受控 `activeTab` 与 `onActiveTabChange`。
- 统一渲染页头、加载、错误、过期、标签页、抽屉和 Toast。
- 将当前概览内容拆成总览内容与策略内容。
- 将页头“阈值”入口改为“预算设置”，保留阈值摘要。
- 处理添加预算、通知聚焦和补价时的标签导航。

### 6.4 `BudgetSummary.tsx`

- 接收已配置预算数量和现有 `BudgetSnapshotSummary`。
- 从三卡扩展为四卡，使用现有语义化数值格式化能力。
- 卡片状态不能仅依赖颜色，必须保留图标、标签和明确数字。

### 6.5 样式与国际化

- 复用成本优化工作台的间距、指标网格和响应式断点，不复制新的平行设计 token。
- 为三标签内容补充稳定的最小宽度、空状态和窄屏布局。
- 新增或调整的文案同时维护 `en` 与 `zh-CN`，namespace 叶子 key 保持一致。
- 动画继续遵循现有 `prefers-reduced-motion` 规则。

## 7. 不变量与错误处理

- Renderer 不直接读写预算配置或会话文件。
- 预算编辑、删除、阈值更新和价格更新仍全部通过现有类型化 preload API。
- 未知模型价格不得猜测；未计价 Token 和计价不完整状态保持原行为。
- 预算保存失败时保留抽屉和字段错误；不得显示成功 Toast。
- 删除失败时保留可恢复的页面上下文，并展示现有错误反馈。
- 标签切换不得清除筛选器、已关闭告警或未完成的抽屉状态，除非切换由明确的跨功能动作触发。
- 通知包含不存在的策略 ID 时，仍进入“预算策略”，但不打开抽屉；一次性聚焦 ID 随后被消费。

## 8. 测试策略

### 8.1 导航与状态测试

- reducer 默认选择预算总览，并能切换三个预算标签。
- 离开预算页再返回时保留预算标签。
- 系统通知导航进入策略标签并聚焦对应策略。
- 不存在的策略 ID 不打开抽屉，但不会造成重复导航。

### 8.2 组件回归测试

- 加载和错误状态保留预算页头，并隐藏就绪内容。
- 就绪状态渲染三个可访问标签及稳定的 tab/panel 关联。
- 总览渲染四张摘要卡、告警和未计价入口，不渲染策略表。
- 策略标签渲染筛选器和策略表，并支持新增、编辑、删除。
- 未计价模型操作切换到价格标签并预填模型。
- 添加预算操作切换到策略标签并打开抽屉。
- 阈值设置在任意标签均可打开，并在保存成功后显示可感知 Toast。
- 键盘方向键、Home 和 End 继续切换标签并移动焦点。

### 8.3 国际化与可访问性

- `tests/i18n.test.ts` 验证中英文 key 对齐。
- 页头动作、标签、抽屉和状态通知具有可访问名称。
- 覆盖层验证初始焦点、Escape 关闭和关闭后的焦点恢复。
- 摘要和风险状态提供文字信息，不以颜色作为唯一信号。

### 8.4 完整验证

实现完成后至少运行：

```text
npm test
npm run typecheck
npm run lint
npm run build
```

本次会修改 Renderer 顶层编排，因此按项目要求额外执行构建验证。

## 9. 验收标准

- 预算菜单具有与成本优化菜单一致的工作台级页头、状态反馈和受控标签体验。
- 用户可在“总览”“预算策略”“模型价格”之间使用鼠标或键盘切换。
- 总览只呈现预算健康信息和可行动告警，策略管理位于独立标签。
- 添加预算、系统通知和未计价模型补价均能到达确定的目标标签与编辑上下文。
- 阈值设置可从任意预算标签进入，保存后预算快照和 Toast 正确更新。
- 加载、失败或过期时页面仍清楚说明当前功能和数据状态。
- 原有预算计算、通知去重、模型计价、持久化格式与 IPC 契约保持不变。
- 中英文、键盘操作、焦点管理和窄屏布局通过相关自动化测试。

## 10. 需要确认的范围

本设计采用“前端工作台重组”范围：不增加新的预算算法或后端数据，只重新组织现有能力并补齐导航与状态一致性。设计确认后，将另行编写中文实施计划，并按红—绿—重构拆分代码任务。
