# 概览自定义日期范围设计

本设计已确认。

## 使用方式

用户可以在概览查看任意一段历史日期的 Token、预估费用与会话活动。例如，选择 11 月 1 日至 11 月 15 日后，概览显示这 15 天的合计和趋势，活动日历也定位到 11 月 15 日所在周。

1. 在概览顶部「今天 / 近 7 天 / 近 30 天 / 全部」右侧增加「自定义」。点击后打开日期对话框，包含「开始日期」「结束日期」「取消」和「应用」。使用带标签的原生日期输入。
2. 首次打开时，用当前预设对应的起止日预填。「全部」从最早的有效历史会话开始日填到今天，没有有效历史会话时两端都填今天。编辑已应用的自定义范围时，预填该范围。
3. 两端必填，允许同一天，结束日最晚为本地今天。缺少日期、日期无效、开始日晚于结束日或选到未来时，提示具体原因。只有有效范围可以应用。允许选择早于首条会话的日期。
4. 只有点击「应用」才更新概览。取消或按 Esc 会丢弃本次编辑。应用后仅「自定义」显示选中，概览标题旁显示本地化的完整起止日期。再次点击「自定义」可编辑，点任一预设即可退出。
5. 自定义选择仅作用于概览。本次打开应用期间，刷新数据、切页再回来都保留已应用范围。在其他页面选择预设时，该预设照常共享。回到仍在自定义模式的概览，继续显示之前选的日期。重新启动应用后，概览使用上次保存的共享预设。

## 统计口径

- 两端都按本地自然日计入。用会话的 `startedAt` 判断归属，从开始日的本地零点取到结束日次日零点之前。结束日是今天时，只纳入开始时间不晚于当前时刻的会话。日期边界按日历进位，涵盖闰日、跨年和夏令时。
- 概览的总 Token、缓存比例、输出及推理 Token、会话数、去重项目数和本地预估费用均来自同一批入选会话。范围内没有会话且数据源有历史记录时，显示「所选日期范围内没有会话」、所选日期和修改入口。整个数据源为空时沿用原有空态。刷新中及刷新失败时保留现有数据状态提示。
- 自定义范围按**会话开始日**归集整场用量和费用，界面在日期旁标注「按会话开始日统计」。例如，会话于 11 月 1 日 23:50 开始，11 月 2 日 00:10 又产生用量。只选 11 月 1 日时，卡片和趋势都包含这场会话的全部 Token 与预估费用。只选 11 月 2 日时，这场会话不计入。
- 现有预设的每日费用按用量片段发生日汇总。自定义模式复用同一套逐片段计价与旧会话回退逻辑，只调整结果的日期归属。每个片段只计价一次，同时累加到总额与对应日期。未计价 Token、假设价格及条件计价提示随对应范围展示。

## 趋势与活动日历

**趋势覆盖所选的首尾日期。** 目前折线只取最后 24 个有记录的日期，直接套用会漏掉长区间的前半段。建议自定义范围最多画 31 个点，使完整自然月可以逐日阅读。更长的范围从开始日划分连续日期段，每段天数为「总自然日数 ÷ 31」向上取整，末段截止到结束日。例如，90 天按连续 3 天汇总，共 30 个点。各段展示 Token 和本地预估费用的合计，图例注明粒度，悬停或键盘聚焦可读出实际起止日和计价状态。没有会话的日期段显示为零。只有一个日期时保留一个可聚焦的点。

**活动日历沿用 53 个完整自然周。** 自定义模式以所选结束日所在周作为最右一列，使用与会话统计一致的本地日期键。区间内的零用量日可聚焦并显示 0 Token。区间外的历史日期与真正晚于本地今天的占位有各自的外观，均不可聚焦。若开始日早于日历最左一列，在日历标题下写明实际可见的起止日期。卡片和趋势仍覆盖整个所选区间。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 选择同一天，两端附近都有会话 | 当日零点开始的会话计入，次日零点开始的会话排除。结束日为今天时排除未来时间戳，非法开始时间也排除。 |
| 本地日与 UTC 日不同，或跨月、跨年、闰日、夏令时 | 卡片、趋势与日历使用相同的本地日期。夏令时切换不会多计或少计一天。 |
| 跨午夜会话混合已计价和未计价用量 | 整场归到开始日，各段费用先求和、再按界面精度取整后与卡片金额一致，未计价 Token 仍可见。 |
| 选择一个月、90 天或超过 53 周的历史 | 一个月可逐日读取。90 天示例包含第一天和最后一天。年度日历注明可见范围。区间中的空白日期段可读为零。 |
| 编辑后取消、切页、刷新、重启 | 取消保留原筛选。切页和刷新保留本次范围。其他页继续使用共享预设。重启恢复共享预设。 |
| 从区间空态或窄窗口重新选择 | 能编辑日期或切回预设。中英文布局在应用最小窗口中可用，键盘可完成打开、填写、应用和取消。 |

设计确认后，实施依次覆盖日期过滤与费用归属、工具栏与概览状态、趋势与活动日历。每部分先写行为测试，再实现并运行相关用例。最终运行 `npm test`、`npm run typecheck` 和 `npm run lint`，并在 Electron 验证日期输入、最小窗口布局和焦点恢复。
