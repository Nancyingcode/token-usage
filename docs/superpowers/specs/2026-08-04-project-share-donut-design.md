# 项目占比环形图设计

## 背景与目标

当前“项目”页通过表格逐行展示项目名称、占比条、会话数、Token 数和最后活跃时间。用户希望将项目占比改为环形图展示，移除列表，并在 hover 时查看详细信息。

本次变更只调整 Renderer 的项目页展示与交互，不改变项目聚合、时间范围筛选和项目下钻的数据流。

## 页面结构

保留现有页面标题、说明和项目数量。用一个居中的图表面板替换整张项目表：

- 面板主体是一个多分段 SVG 环形图，每个项目占据的弧长与 `totalTokens` 占全部项目 Token 的比例一致。
- 环形中心显示当前筛选范围内的总 Token，并配有本地化标签。
- 不显示原有数据表；在环形图旁显示紧凑的常驻图例，每项包含与分段一致的颜色标记、项目名称和占比。
- 项目按现有 `UsageProject[]` 顺序绘制，保持与聚合层按 Token 降序的规则一致。
- 使用一组具名图表颜色循环分配项目分段；相邻分段使用不同颜色。颜色只用于区分类别，不承担状态或严重程度含义。

图表直接使用现有 `UsageProject` 数据，不引入新的运行时依赖。比例从各项目 `totalTokens` 与图表项目总量计算，避免依赖可能因舍入而不精确闭合的 `shareOfTotal`。

## 交互设计

每个项目分段是独立的可交互目标：

- 鼠标移入分段时显示详情浮层，移出时关闭。
- 键盘 Tab 聚焦分段时显示同一浮层，失焦时关闭。
- 点击分段，或在聚焦时按 Enter/Space，继续调用现有 `onProjectSelect(projectPath)`，进入该项目的会话筛选视图。
- hover、focus 和 active 分段通过加粗描边/轻微外移强调，不只依靠颜色变化表达当前目标。

图例与图表使用同一份分段数据和颜色序号，确保颜色映射稳定一致。图例项支持 hover/focus 高亮对应分段，点击后执行相同的项目下钻。桌面宽度下图例位于环形图右侧，窄窗口下移到图表下方并自动换行/滚动，项目名称过长时截断但保留完整路径提示。

浮层跟随分段中点定位，并限制在图表面板范围内。浮层展示：

- 项目名称与完整路径；
- 占总 Token 的精确百分比；
- Token 总数；
- 会话数；
- 最后活跃时间。

对于极小占比项目，可见弧长仍按真实比例绘制，不人为放大以免误导；交互描边提供比可见线条更宽的命中区域。

## 可访问性与国际化

- SVG 提供本地化的图表名称和说明。
- 每个分段提供包含项目名称、占比、Token、会话数和最后活跃时间的本地化可访问名称。
- 分段支持 Tab、Enter 和 Space；focus 与 hover 获得相同信息和视觉反馈。
- 浮层内容使用现有 locale formatter 格式化数字、百分比和日期。
- 新增或修改的用户可见文案同时维护英文和简体中文资源，不在组件中硬编码。
- 尊重 `prefers-reduced-motion`，分段强调不依赖必要动画。

## 边界情况

- 项目数据为空时沿用上层已有的期间空状态，不在图表组件内重复空状态。
- 总 Token 为零时绘制空环，中心显示 0，不生成不可操作的项目分段。
- 项目数量较多时仍绘制全部项目；颜色可以循环，但每个分段的浮层和可访问名称独立标识项目。
- 无效最后活跃时间继续使用现有“未知日期”本地化回退。

## 测试与验证

按红—绿—重构执行：

1. 先更新项目视图测试，证明项目表和列表行已移除，环形图、中心总量、颜色对应的项目图例及本地化可访问名称存在。
2. 添加交互测试，证明 pointer hover 与键盘 focus 会显示详情，移出/失焦会关闭详情，点击及 Enter/Space 会传递完整项目路径。
3. 添加多项目几何测试，证明分段比例和累计偏移由 Token 占比稳定计算，输入数据不被修改。
4. 更新应用内容集成测试，证明“项目”入口渲染环形图而非表格。
5. 更新或移除只约束旧项目表按钮样式的测试，并为环形图的焦点、命中区域和浮层样式添加最小必要断言。
6. 完成后运行 `npm test`、`npm run typecheck` 和 `npm run lint`。本次不修改 Electron 主进程、preload 或构建配置，因此不要求额外运行构建。

## 非目标

- 不修改项目聚合算法或 `UsageProject` 类型。
- 不增加项目筛选、排序、合并“其他”项目或图表分页。
- 不改变点击项目后进入会话页的现有导航行为。
- 不在概览页或性能页替换其他图表。
