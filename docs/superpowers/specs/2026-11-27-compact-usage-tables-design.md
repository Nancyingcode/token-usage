# 会话与项目列表窄窗口设计

## 列表布局

- 按列表容器的可用宽度切换布局。低于宽版表格所需宽度时，会话列保留名称、总 Token 和状态，项目列保留名称、总 Token 和查看会话入口。两种布局都展示精确 Token 数。
- 会话的行详情展示输入、缓存、输出、开始日期、项目名称和路径。项目的行详情展示路径、用量占比、会话数、单会话平均用量、缓存占比和最后活跃时间。宽窗口沿用原有列。两张表使用现有用量数据，本地估算费用继续在已有费用视图中查看。
- 窄窗口允许长名称、路径和数值换行。项目筛选、会话诊断、项目查看会话、排序和分页沿用已有入口和规则。

## 展开与焦点

每行用原生详情控件展开和收起。按 Enter 或空格后，焦点留在原控件。放宽窗口时，正在聚焦的控件保留到焦点移开，避免键盘导航中断。仅调整窗口尺寸时，同一行保留展开状态。筛选、排序或翻页重建列表时，详情随原行卸载。

## 验收

在 1024 × 680 的 Electron 窗口，无需横向滚动即可找到高用量会话和项目，读取总量并打开相应详情。检查双向调整宽度、键盘焦点、长名称和路径、较大 Token 数、空态及下钻。覆盖英文、简体中文和深浅色主题。宽窗口检查完整表头及列值。
