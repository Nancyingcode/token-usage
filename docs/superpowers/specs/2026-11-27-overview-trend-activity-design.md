# 概览趋势与活动日历设计

## Token 用量趋势

- 趋势副标题说明汇总粒度。预设周期和逐日的自定义区间显示「按日汇总」，较长自定义区间沿用现有分组并显示「每 N 天汇总」。
- 纵轴以零为基线，按最大用量选取 3 至 4 个易读的刻度。刻度和折线共用同一比例。最高的非零数据点旁显示本地化缩写数值，多个点同值时标注最早的点。
- 单日仍能聚焦查看数值。悬停和键盘详情继续提供完整 Token 数、费用及计价状态。费用卡继续显示所选周期的本地估算费用。

## 活动日历

- 周日到周六算一个自然周。所选周期覆盖不足 53 周时，默认呈现包含起止日的所有周。原有 53 周视图可用同一按钮展开和收起，末周始终包含所选结束日。
- 切换仅调整显示的周数。选中区间内的零用量格为素色，区间外历史日期保留淡纹理，未来日期保留空位。区间内的格子可以用鼠标或键盘查看日期和 Token。
- 「全部」和覆盖至少 53 个自然周的区间沿用 53 周布局。超出可见窗口的自定义区间继续显示截断说明。
- 英文和简体中文同步维护按钮及汇总粒度文案。月份与星期保持对齐，切换后焦点留在原按钮。自动刷新保留展开状态，新筛选从默认周数开始。

日期分组、费用归属与 53 周窗口延续已有设计。[自定义日期范围](2026-11-26-overview-custom-date-range-design.md) · [活动日历](2026-08-10-overview-activity-calendar-design.md)

## 验收

用合成数据验证刻度与折线位置、峰值和费用详情。验证跨月短区间、零用量、未来占位以及展开前后的筛选边界。在 1024 × 680 的 Electron 窗口验证中英文提示和切换，并覆盖浅色、深色主题。
