# 动画效果升级设计

设计已于 2026-11-27 确认。优先改善概览读数的连续性，其次为自定义日期和窄窗口行详情补上操作反馈。[实施计划](../plans/2026-11-27-animation-upgrade.md)

## 概览为什么会重复播放

目前概览用筛选范围、会话数、总 Token 和最后一个有数据的日期共同生成指标区和趋势图的 React key。同一范围收到新数据时，总量变化就会重新挂载整张图，正在查看的日期可能丢失键盘焦点和提示。现有 CSS 让折线等待 420 ms 再绘制 750 ms，日历入场也有 700 ms 延迟。[概览组件](../../../src/renderer/components/Overview.tsx) · [视图样式](../../../src/renderer/styles/views.css)

页面切换、导航、列表入场和 Tooltip 已有动效。指标值也已经能在显示文本变化时单独更新。本次沿用现有 CSS、React 组件和 140 / 180 / 220 ms 时长令牌，改动集中在 Renderer。[第一阶段设计](2026-08-11-animation-enhancements-design.md) · [第二阶段设计](2026-08-11-animation-feedback-phase-two-design.md) · [动效令牌](../../../src/renderer/styles/tokens.css)

## 概览在何时播放

| 用户看到的变化 | 建议效果 | 操作与读数 |
| --- | --- | --- |
| 首次进入概览、从其他页返回，或从加载态、空态进入有数据的概览 | 沿用页面的 180 ms 短淡入和小幅上移，指标、折线和日历同步就位 | 取消逐卡等待与延迟画线。最终数字、峰值和数据点从内容挂载时即可读取或聚焦 |
| 从「周」切到「月」，或应用不同的自定义日期 | 工具栏立即标出选中项。新曲线与数据点在最终位置做一次 140 ms 的透明度过渡，轴、标签和命中区域直接更新 | 焦点留在发起操作的控件。快速切换立即显示最后一次选择，进入空区间时直接呈现对应空态 |
| 同一范围手动刷新或收到后台更新，且概览仍有数据 | 曲线和日历就地更新，只有显示值改变的指标使用已有的数值反馈 | 聚焦日期仍存在时保留原节点，提示同步最新数值。日期移出后收起旧提示。保留日历展开状态和仍适用的滚动位置 |
| 重选当前范围、取消日期草稿，或只展开和收起 53 周日历 | 重选与取消直接返回。展开和收起只切换日历布局 | 按钮立即反映展开状态，焦点留在按钮，沿用结束周定位。月份、星期和日期格同时到位 |

页面入场由现有页面容器负责，首屏指标跟随页面一起出现。数据更新时按日期复用已有的趋势点，即使会话数或总 Token 改变，也能保留原节点。主动更换范围时只给图形层播放反馈。日历继续用筛选范围决定何时恢复默认周数。[指标值组件](../../../src/renderer/components/AnimatedValue.tsx) · [趋势与日历设计](2026-11-27-overview-trend-activity-design.md)

## 两个局部交互

- **自定义日期。** 打开时面板在 180 ms 内从下方小幅移入，遮罩同步淡入。继续使用原生模态对话框管理焦点。校验失败时保留草稿和错误提示。有效提交、取消和 Esc 均立即关闭，焦点返回可见的日期按钮或紧凑模式的下拉触发器。只有真正应用了新范围才触发图表反馈。[日期对话框](../../../src/renderer/components/DateRangeDialog.tsx) · [工具栏](../../../src/renderer/components/Toolbar.tsx)
- **会话与项目的行详情。** 点击或用 Enter、空格操作「详情」时，箭头在 140 ms 内转到对应方向。字段随原生展开状态立即显示或收起，焦点留在原控件。只动箭头，便于用户连续开合时追踪同一行。窗口宽度跨过断点时沿用当前行的展开状态和焦点规则。[行详情组件](../../../src/renderer/components/UsageRowDetails.tsx) · [窄窗口列表设计](2026-11-27-compact-usage-tables-design.md)

## 减少动态效果与退场中断

系统开启「减少动态效果」时，上述场景立即呈现最终状态。趋势点聚焦时直接显示高亮与提示，详情箭头直接指向最终方向，日期对话框仍有静态遮罩和清晰的焦点。

已有抽屉、确认框和 Toast 在发起关闭时读取系统偏好，普通模式下随后等待自身的退场动画结束。如果退场期间开启减少动态效果，或退场动画被取消，仍在页面上的组件应立即完成已请求的操作，且只执行一次。子元素或先前入场动画的结束事件不能提前触发确认。父页面卸载时清理等待，避免迟到的确认或关闭回调影响新页面。[退场逻辑](../../../src/renderer/hooks/useExitTransition.ts) · [退场交互测试](../../../tests/overlayExitTransitions.test.tsx)

## 验收

1. 用合成数据在概览中键盘聚焦某一天，推送同一天 Token 增加的扫描结果。断言原节点仍持有焦点、提示读出最新数字，趋势面板与日历没有重新挂载。再切换「周 → 月 → 周」并重复应用相同日期，检查最终选项、曲线、峰值与日期一致。[概览测试](../../../tests/overviewTrend.test.tsx)
2. 在 1024 × 680 与宽版 Electron 窗口，分别从下拉菜单和日期按钮打开对话框，验证键盘进入、非法日期、应用、取消、Esc 和焦点返回。展开 53 周再刷新，检查结束周定位与展开状态。键盘展开列表详情并来回调整窗口宽度，检查字段、箭头和焦点。[日期范围测试](../../../tests/overviewDateRange.test.tsx)
3. 在 Electron 检查普通与减少动态效果两种模式的实际计算样式。普通模式检查概览没有延迟画线、行详情只过渡箭头。减少动态效果模式检查图形和控件在首帧到位。退场中切换偏好并重复关闭，验证确认动作只执行一次，模态焦点正确恢复。[退场 Hook 测试](../../../tests/useExitTransition.test.tsx)
4. 实施后运行受影响的组件测试，以及 `npm test`、`npm run typecheck`、`npm run lint`。视觉验收使用仓库 fixture 或独立临时数据，覆盖中英文及深浅色主题。
